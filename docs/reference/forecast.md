# `groundfault.forecast`

The optional part of groundfault for the forecast of the harmonic residual current
([Forecast](../forecast/index.md)). `import groundfault` does not load it; the names of its modules are also available
at the level of the subpackage (`from groundfault import forecast as fc; fc.NetworkModel`).
